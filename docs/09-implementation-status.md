## 已完成：阶段 0 + 阶段 1，以及阶段 2 单目标防守闭环

### 模拟核心

- 纯 TypeScript、固定 `20Hz`、显式 `step()`。
- 相同规则、种子和输入产生相同状态哈希与结果。
- 参数化随机高度地图、量化高度和基础山地阻挡。
- EasyStar 封装的八方向 A*、地形成本和禁止切角。
- 两个敌对势力、每组固定 8 人的步枪编组。
- 编组级移动和成员级健康结果。
- 健康状态与在场状态分轴记录。
- 本地目视发现、最后已知位置和同势力 15 tick 情报延迟。
- 弹匣、射击节奏、换弹和无限备用弹药。
- 同时伤害结算、成员受伤、失能和死亡。
- 压制、士气、溃散、撤离、重新集结入口。
- 冲突模式消灭/溃散、僵局和最大时长终止。
- 冲突/防守模式判别输入，冲突模式保持默认并向后兼容。
- 单个防守目标的占领、争夺、恢复、时限与胜负结算。
- 防守方依据高程、移动成本、目标距离和分散度选择阵位。
- 进攻方在没有相关敌情时向目标推进，并以有效在场成员提供占领力。
- 目标状态、占领进度、双方占领力、目标事件和检查接口。

### 网页观察端

- React、TypeScript、Vite、Three.js 和 React Three Fiber。
- 模拟运行在 Web Worker，主线程只接收渲染帧和检查结果。
- 平滑高度地形、程序化岩石和植被。
- 批量渲染的成员与势力编组标记。
- 根据 `weapon-fired` 事件抽样显示移动曳光和弹着闪光。
- 倾斜正交镜头、平移、旋转、缩放、复位和跟随模式。
- 暂停/继续、新战斗、纯净观察界面。
- 冲突/防守模式切换，每次切换创建独立的新战斗会话。
- 贴合地形的目标区域、边界、占领进度标记和目标状态 HUD。
- 势力概览、编组详情、士气、压制、伤亡、接触和路径信息。
- 页面进入后台时自动暂停。
- 桌面优先、窄屏降级布局。

### 自动验证

- 13 项 Vitest 覆盖地图确定性、合法路径、通信延迟、交火换弹、成员减员、防守布阵、推进中射击、占领状态、模式终止、完整战斗复现和终止冻结。
- 6 项 Playwright 覆盖真实 Worker 暂停/继续、镜头缩放、编组检查、模式切换、桌面/窄屏布局、Canvas 像素非空、目标区和射击曳光可见性。
- 生产构建通过。

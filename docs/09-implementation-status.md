## 已完成：阶段 0 + 阶段 1，以及阶段 2 单目标防守、组合地形与静态掩体规则闭环

### 模拟核心

- 纯 TypeScript、固定 `20Hz`、显式 `step()`。
- 相同规则、种子和输入产生相同状态哈希与结果。
- `map-2` 标准地图 schema，使用 TypedArray 分层保存高度、地表类型、水深、地面阻挡标志和静态对象占用。
- 地表层可表达草地、沙地、泥地、岩石和铺装；水深层可表达无水、浅水和深水，沼泽由泥地与浅水组合表达。
- 参数化随机高度，以及按全图格数兑现的山地、开阔水体和湿地占比；开阔水体包含深浅分层，湿地由泥地与浅水组合生成，不可满足的配额会明确拒绝。
- 按全图格数确定性生成树木、岩石和墙段；对象具有全局稳定 ID、单格锚点和 8 向朝向，对象列表与稠密占用投影会逐格交叉验证。
- 三类静态对象均阻挡步行并以类型高度参与视线；两侧出生部署带和跨图主进攻通道不会被山地、水体或静态对象切断，完整 setup 使用 A* 验证撤离与攻防任务路线。
- 从静态对象稳定字段确定性派生相邻可站立掩体槽位；树木、岩石和墙体容量分别为 2、4、6 名有效成员，冲突槽位按稳定对象 ID 选择。
- 掩体占用在出生与到达时声明，在完成离开、撤离或失去全部有效成员时释放；占用进入状态哈希并通过编组 inspection 投影。
- 命中与发现读取同一方向性掩体效果；正面完整、侧面减半、侧后方和后方无效，容量不足按实际覆盖成员比例缩放。
- 静态地图连通分量在模拟初始化时派生，AI 目标落点只会选择编组当前可达的地形分量。
- 数据表驱动的步行成本矩阵；浅水和沙地减速、泥地浅水组合成本更高、深水不可通行。
- EasyStar 封装的八方向 A*、统一地形成本和禁止切角。
- `BattleSetup` schema 为 `stage-2`、rules 为 `stage-2.3`；地图使用独立 `map-2` 版本，旧版本输入明确拒绝。
- 两个敌对势力、每组固定 8 人的步枪编组。
- 编组级移动和成员级健康结果。
- 健康状态与在场状态分轴记录。
- 本地目视发现、最后已知位置和同势力 15 tick 情报延迟。
- 弹匣、射击节奏、换弹和无限备用弹药。
- 同时伤害结算、成员受伤、失能和死亡。
- 压制、士气、溃散、撤离、重新集结入口。
- 冲突模式消灭/溃散、僵局和最大时长终止。
- 冲突/防守模式判别输入，冲突模式保持默认并向后兼容。
- 单个防守目标的占领、争夺、恢复、时限与胜负结算。
- 防守方依据高程、移动成本、目标距离和分散度选择阵位。
- 进攻方在没有相关敌情时向目标推进，并以有效在场成员提供占领力。
- AI 决策刷新不会取消已经开始的单格移动；被静止友军持续挡路时会使用确定性的动态障碍 A* 绕行，友军遮挡射线时后排会寻找相邻射击位。
- 目标状态、占领进度、双方占领力、目标事件和检查接口。

### 网页观察端

- React、TypeScript、Vite、Three.js 和 React Three Fiber。
- 模拟运行在 Web Worker，主线程只接收渲染帧和检查结果。
- 平滑高度地形，以及直接消费权威静态对象列表的实例化树木、岩石和墙体。
- 地表、水深和地面阻挡标志驱动的基础地形顶点色；深水、浅水和湿地水斑使用独立批量水面，静态对象不会生成在水体或保留路线中。
- 批量渲染的成员与势力编组标记。
- 根据 `weapon-fired` 事件抽样显示移动曳光和弹着闪光。
- 倾斜正交镜头、平移、旋转、缩放、复位和跟随模式；初始与复位缩放会按地图跨度和画布宽度自适应。
- 暂停/继续、新战斗、纯净观察界面。
- 冲突/防守模式切换，每次切换创建独立的新战斗会话。
- 贴合地形的目标区域、边界、占领进度标记和目标状态 HUD。
- 势力概览、编组详情、士气、压制、伤亡、接触和路径信息。
- 页面进入后台时自动暂停。
- 桌面优先、窄屏降级布局。
